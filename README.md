# web_wisata_kalimantan
Website wisata Kalimantan berbasis HTML, dan CSS

# 🌴 Wisata Kalimantan Barat

Website statis yang menampilkan 35 destinasi wisata menarik di Provinsi Kalimantan Barat. Dibuat dengan HTML dan CSS murni, dirancang responsif untuk semua ukuran perangkat.

## ✨ Fitur Utama

- **35+ Destinasi Wisata**: Informasi lengkap meliputi nama, lokasi, dan deskripsi
- **Responsif Mobile**: Tampilan optimal di smartphone, tablet, dan desktop
- **Navigasi Sticky**: Menu navigasi yang selalu terlihat saat scroll
- **Grid Modern**: Tata letak card menggunakan CSS Grid
- **Animasi Hover**: Efek interaktif pada card destinasi
- **Smooth Scroll**: Pergantian antar section yang halus

## 🗺️ Struktur Halaman

1. **Beranda** - Header dengan judul utama
2. **Destinasi Wisata** - Grid berisi 35 tempat wisata
3. **Tentang** - Informasi dan fakta menarik Kalimantan Barat
4. **Kontak** - Informasi kontak Dinas Pariwisata

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Font Awesome (melalui ikon statis)
- Google Fonts (fallback system fonts)

## 📱 Responsivitas

Website mendukung berbagai ukuran layar:
- **Desktop**: > 992px
- **Tablet**: 768px - 992px
- **Mobile Landscape**: 576px - 768px
- **Mobile Portrait**: < 576px
- **Mobile Extra Small**: < 375px

## 🖼️ Sumber Gambar

Gambar destinasi diambil dari berbagai sumber eksternal:
- ik.imagekit.io
- suarakalbar.co.id
- amazingborneo.id
- Wikimedia Commons
- Dan sumber lainnya (bersifat ilustrasi)

> ⚠️ **Catatan**: Gambar menggunakan URL eksternal, pastikan koneksi internet aktif.
